# 平度当地美食地图（静态网站）

一个纯静态的美食地图网站，展示平度当地推荐美食，支持随时添加、删除、编辑数据。

## 目录结构

```
.
├── index.html          # 页面入口
├── css/style.css       # 样式
├── js/app.js           # 交互逻辑
├── data/foods.json     # 美食数据（初始推荐）
└── README.md
```

## 运行方式

由于浏览器对 `file://` 下的 `fetch` 有限制，请通过本地服务器打开：

```bash
# 方式一：Python
python3 -m http.server 8000

# 方式二：Node
npx serve .
```

然后访问 `http://localhost:8000`。

## 数据管理

### 初始数据
写入在 `data/foods.json`，目前为平度市官方公布的十大名吃（均为「推荐」状态）。

### 增 / 删 / 改（无需后端）
- 点击 **「+ 添加美食」** 新增一条；
- 每条卡片有 **编辑 / 取消推荐（恢复推荐）/ 删除** 按钮；
- 不好吃的可以点 **删除** 或 **取消推荐**，数据不会丢失但会从推荐列表移除。

所有改动默认保存在浏览器 `localStorage`（覆盖层），刷新不丢。

### 永久保存到 foods.json
- 点击页面底部 **「⬇ 导出数据」** 下载最新 `foods.json`；
- 用下载的文件**覆盖** `data/foods.json` 即可完成永久保存；
- 若想清除本地改动、回到初始数据，点 **「↺ 重置为初始数据」**。

### 手动编辑 foods.json
每条数据字段说明：

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识（字符串） |
| `name` | 美食名称 |
| `category` | 类别，如 面食 / 小吃 / 熟食 |
| `recommended` | `true` 推荐，`false` 已取消推荐 |
| `desc` | 简介 |
| `address` | 地址 / 所属镇街 |
| `lng` / `lat` | 经纬度（用于在示意地图上定位，可留空） |

## 说明
地图为示意性点位图（基于各镇/街道大致经纬度摆放），便于直观查看分布，非精确导航地图。
